How to read this (rules, from README §2): `wtd` = .30 cause + .20 necessity + .20 catalyst + .15 basket + .15 price, where price is computed from depth vs own history (dd_pctile), 12-month trend vs SPY and stabilizing; R/R < 1.3 is "thin" and costs 1 point.
Buckets: avoid = cause ≤ 3 · buy = cause ≥ 7 and (stabilizing or catalyst ≥ 7), not thin, #1 in its theme · core = broad fund (utilities, grid/infra, gold, staples, industrials, materials, realestate, banks) with cause ≥ 7 and necessity ≥ 8, not thin, #1 in theme, held long term with no stop · alt = qualifies but not #1 in theme · watch = everything else.
TP = back to the 52-week high; SL = 1.5 monthly sigma below today; R/R = TP / |SL|. Risk parity sizes each buy so every stop loses the same dollars.
dip# = depth rank among candidates (1 = most beaten up). It is depth, not quality: "my #" is the panel's order.
